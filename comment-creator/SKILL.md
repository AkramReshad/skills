# Comment Creator

Keep each comment to one paragraph maximum. Describe only context needed to understand the final code. Remove references to the conversation, prompt, user, prior drafts, rejected alternatives, corrected misunderstandings, explored branches, and incidental choices encountered during implementation. Do not preserve a negative merely because it was discussed. Include rationale only when it remains a durable constraint on the code.
